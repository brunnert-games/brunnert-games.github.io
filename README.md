# Brunnert Games

A simple web page for games developed with my kids.

## Preview locally

Run `python3 -m http.server` in the repository root, then visit
<http://localhost:8000>.

## Publish

In the repository's **Settings → Pages**, choose **Deploy from a branch** and
select the branch containing `index.html` and the `/ (root)` folder. GitHub
Pages will publish the site at <https://brunnert-games.github.io/>.
